# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Fork the repository and create a focused branch.
2. Build with `swift build` and run `swift test`.
3. Keep changes compatible with macOS 14 or later.
4. Add tests for timestamp-engine behavior changes.
5. Open a pull request that explains the behavior and verification performed.

Please do not include unrelated formatting or generated files from `.build/`
or `dist/` in a pull request.
